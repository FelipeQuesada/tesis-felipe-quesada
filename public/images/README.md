# Carpeta de Imágenes

Coloca aquí todas las imágenes que uses en el frontend de la aplicación.

## Imágenes necesarias para la página principal:

### Blog Section:
- `blog-resina-epoxi.jpg` - Imagen para el artículo "Fundas con Resina epoxi: Las mejores ideas"
- `blog-ceramica.jpg` - Imagen para el artículo "¿Qué es la cerámica moderna?"

### Learn Section:
- `learn-illustration.png` - Ilustración 3D del personaje señalando (150x150px recomendado)

### Why Section:
- `benefit-creativity.png` - Ilustración de creatividad (bombilla, lápices, libros, engranajes)
- `benefit-community.png` - Ilustración de comunidad/ambiente

## Notas:
- Las imágenes se cargarán automáticamente desde `/images/[nombre-archivo]`
- Si una imagen no existe, se ocultará automáticamente sin romper el diseño
- Formatos recomendados: JPG para fotos, PNG para ilustraciones con transparencia
- Tamaños recomendados: 400x300px para tarjetas de blog, 150x150px para ilustraciones
